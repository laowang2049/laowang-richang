# laowang-richang

老王 —— N 种适合日常更新的视频类型制作。

这个仓库用来沉淀那些**门槛低、能日更、能起号**的视频做法：每种类型一套玩法，写清楚怎么做、发什么、注意什么。

---

## 目前收录的类型

### 1. 单图互动型
- **画幅**：16:9 横版
- **形式**：一张黑白线稿 + 顶部一句提问
- **目的**：勾评论区，让人在评论里接自己的故事
- **要点**：文案是灵魂，一句 28 字以内的疑问句，场景具象、有情感留白

### 2. 图文拼接型
- **画幅**：3:4 竖版
- **形式**：一段文案 + 下半张配图
- **目的**：蹭热门音频的流量
- **要点**：**发布必须配回原音频**，配错等于白做；文案 200 字以内最舒服

### 3. vibe 知识大赏
- **画幅**：可选 9:16 / 16:9
- **形式**：代码动画 + 背景音乐，无人声旁白
- **目的**：知识感、氛围感，制作成本低
- **要点**：开工前定好主题、时长、画幅、背景音四样

## 目录规划

```
laowang-richang/
├── type1-单图互动/      # 第 1 类的文案模板、排稿规则、案例
├── type2-图文拼接/      # 第 2 类的文案清洗规则、配图风格、发布 checklist
├── type3-vibe知识/      # 第 3 类的选题库、画风、bgm
└── notes/               # 日常更新笔记
```

以后新类型进来就按 `typeN-名字/` 接着加。
